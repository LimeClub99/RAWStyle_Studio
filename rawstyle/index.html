Apply in Lightroom

Apply the predictions in Lightroom Classic using the bundled plug-in.

  1. Once: In Lightroom Classic, File → Plug-in Manager → Add the bundled RAWStyle Lightroom.lrplugin folder.
  2. Import your new RAW shoot and select the photographs to edit.
  3. Choose Library → Plug-in Extras → Apply RAWStyle Predictions… and select the predictions file.
